# 参考项目研究

参考仓库：[dm9717/flower-classification](https://github.com/dm9717/flower-classification)。本文件只记录阅读后的设计启发，不复制其代码。

## 观察到的做法

- 项目按 notebook 拆分数据可视化、基础 ResNet18、数据增强版本、超参数调试和评估指标。
- 数据使用按类别组织的花卉图片目录，训练阶段使用裁切、水平翻转、颜色变化和仿射变换。
- 训练过程区分训练与验证阶段，保存验证集表现较好的模型，并使用 TensorBoard 记录过程。
- 评估阶段统计混淆矩阵和各类别指标，帮助定位容易混淆的花卉类别。

## 本项目的独立实现

- 使用 Pandas 清单记录图片尺寸、模式、可解码状态和 SHA-256，避免相同内容图片泄漏到不同集合。
- 使用 PIL 和 PyTorch Dataset 自行实现读取和增强，不依赖 torchvision 的数据集或模型实现。
- 手动实现残差块和 ResNet-18，使用自己的训练、测试、混淆矩阵和单张预测脚本。
- 使用五类公开花卉数据先跑通闭环，再保留参数化入口支持替换成其他类别数据。

参考仓库使用预训练迁移学习作为主要实验路线；本项目按考核要求把手写 ResNet 作为主模型，迁移学习只作为后续可选对照实验，避免把预训练模型当作手写实现的替代品。

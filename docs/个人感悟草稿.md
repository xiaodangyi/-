## 可以保留的技术体会

1. 先检查图片是否能完整解码，再训练模型，能把数据问题和模型问题分开。
2. 分层划分不仅要看类别比例，还要检查重复图片；否则测试集可能包含训练集已经见过的内容。
3. 残差连接让输入可以沿捷径传到后层，减轻深层网络训练时的梯度传递困难。
4. 总体准确率之外还要看混淆矩阵和每类准确率，才能知道模型具体在哪些类别上失败。
5. Git 的小步提交能记录从数据分析到训练改进的真实过程，也方便回退和比较实验。

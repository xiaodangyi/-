# 验收视频操作指南

本文指令适用于当前 Windows 电脑，工作目录为 `E:\新建文件夹 (8)`。按顺序在同一个 PowerShell 窗口运行；新开窗口后先重新执行初始化部分。现有依赖、训练数据和正式模型已经准备好，录屏前无需再次安装或下载数据集。

## 一、当前效果与演示边界

正式模型为 `outputs/experiment-002/best.pt`，使用手写 ResNet-18 从随机参数开始训练 30 轮，按验证集准确率选择第 30 轮的模型。

| 指标 | 实测值 |
| --- | --- |
| 训练集准确率 | 97.85% |
| 最佳验证集准确率 | 81.34% |
| 测试集准确率 | 84.48%，468/554 |
| 测试集宏平均 F1 | 0.8417 |

这是可展示完整学习流程的基线。训练和验证准确率相差约 16.51 个百分点，提示过拟合；模型对已见过的训练数据学得较好，对新图片的泛化仍有提升空间。测试集来自同一公开数据集，84.48% 不能代表所有网络图片上的准确率。

| 类别 | 中文 | 测试集中该类识别正确的比例（召回率） |
| --- | --- | --- |
| daisy | 雏菊 | 86/96，89.58% |
| dandelion | 蒲公英 | 115/135，85.19% |
| roses | 玫瑰 | 67/97，69.07% |
| sunflowers | 向日葵 | 97/106，91.51% |
| tulips | 郁金香 | 103/120，85.83% |

玫瑰是当前较弱的类别：97 张中有 16 张误判为郁金香。当前模型只支持以上五类；其他花、动物或日常物品也会被强制分到其中一类，尚不具备可靠的“未知类别”检测能力。输出概率是在这五类之间的相对分配，不是经过校准的正确率保证。

## 四、现场展示训练

验收视频可以展示 2 轮实际训练，再展示正式 30 轮实验的曲线与结果。务必说明这 2 轮用于演示训练过程，最终识别仍使用已完成 30 轮的正式模型。

```powershell
$trainingDemo = Join-Path $demoRoot 'training-demo'
& $python -s -u .\scripts\train.py --manifest-dir .\data\processed --data-dir .\data\raw --output-dir $trainingDemo --epochs 2 --batch-size 32 --image-size 224 --device cuda --seed 42 --log-every 10
```

每轮有 81 个训练批次和 18 个验证批次。讲解“前向预测 → 计算交叉熵损失 → 反向传播 → AdamW 更新参数”，再解释验证阶段不更新参数、只检查效果。如果希望每批都显示，将 `--log-every 10` 改为 `--log-every 1`。

`Ctrl+C` 可中断当前训练。已有最佳模型和完整轮次日志会保留，但当前版本不支持断点续训。重新演示请生成新的 `$demoRoot` 或使用新的输出目录。

如果想正式重新训练完整 30 轮，也可使用现有启动脚本。它会自动生成独立的实验目录；不要为了录屏而反复训练：

## 六、用网络图片现场识别

先打开专门存放外部演示图片的目录：

```powershell
New-Item -ItemType Directory -Path '.\data\demo_images' -Force | Out-Null
Invoke-Item -LiteralPath '.\data\demo_images'
```

在浏览器中打开原始图片，使用“图片另存为”保存到 `E:\新建文件夹 (8)\data\demo_images`。先选择五类之内、主体清晰的一朵花，例如命名为 `rose01.jpg`、`sunflower01.png`。记录图片来源链接；演示时如使用与原数据集相同的图片，应如实说明，不能宣称是全新样本。

图片应是真实的 JPG、PNG、BMP 或 WebP 文件。下载到的是网页、HEIC 或 AVIF 时，应先用支持它的图片软件另存为 PNG/JPG；直接改扩展名不能完成格式转换。保存对话框中确认目标为 E 盘，避免默认保存到 C 盘下载文件夹。

先展示图片，再运行识别：

```powershell
$image = 'E:\新建文件夹 (8)\data\demo_images\rose01.jpg'
Invoke-Item -LiteralPath $image
& $python -s .\scripts\predict.py --checkpoint $checkpoint --image $image --device cuda
```

请把 `rose01.jpg` 换成真实文件名。程序按概率从高到低输出五类；第一行是本次预测类别，例如 `roses: 0.8700` 表示五类中玫瑰的输出概率约为 87%，不是保证一定正确。将 `$image` 改为另一张图片路径，再次运行最后一条命令即可。

如希望逐个识别目录中的全部图片：

```powershell
Get-ChildItem -LiteralPath '.\data\demo_images' -File |
    Where-Object { $_.Extension.ToLowerInvariant() -in @('.jpg', '.jpeg', '.png', '.bmp', '.webp') } |
    ForEach-Object {
        Write-Host ('正在识别：' + $_.Name) -ForegroundColor Cyan
        & $python -s .\scripts\predict.py --checkpoint $checkpoint --image $_.FullName --device cuda
    }
```

该循环每张图片重新加载一次模型，适合少量录像样例。预测不会更新模型，也不会自动学习新图片；如需学会新类别，需要带标签的数据、调整类别数并重新训练。

当前项目是命令行程序，运行预测脚本时会加载模型并在终端输出结果，不需要启动网页服务。图片预览由 Windows 默认图片程序负责。图片下载到本地后，推理可以离线进行。

## 七、后续改进顺序

以下是建议方案，尚未实施；不能把预期提升写成已经获得的成绩。

1. **先改进训练增强和正则化。** 在保留手写网络的基础上尝试温和的随机缩放裁切、颜色扰动，让模型更少依赖背景；比较标签平滑 0.05/0.1、权重衰减等设置。过强增强也可能破坏花形，需要用验证集比较。
2. **补充可靠、独立的训练样本。** 优先补充玫瑰、郁金香不同角度、背景和光照的带标签图片。新增内容要做去重并检查标签；同来源的近似图片避免跨集合。外部演示图片作为独立检查时不加入训练。
3. **按验证集比较实验。** 一次改变一个主要因素，记录数据版本、种子、配置、最佳验证准确率和宏平均 F1；可根据验证曲线设置早停。只有验证表现改善才考虑替换正式模型。由于当前测试结果已经查看，后续不要围绕其错误反复调参；新一轮最终评估最好另外保留一批未参与改进决策的独立图片。
4. **再改善输入与展示。** 可检查照片方向信息、主体裁切和低置信度提示。置信度阈值本身不能可靠识别所有未知物体，需要另行验证。输入预处理有变化时，应在验证集上检查，并保持评估与预测一致。

训练轮数更多或网络更大并不保证更好；当前已有明显训练/验证差距，优先解决泛化问题。预训练迁移学习可以作为额外对照，按本次考核要求，手写残差块和 ResNet 仍需保留为主要实现。

# 花卉分类验收演示：环境、结果与识别

按“运行项目，展示主要结果”的要求，依次展示真实环境、已有结果和网上图片识别。使用已经训练好的模型。

**一、启动项目，展示运行环境**

打开 PowerShell，复制这两行：

```powershell
Set-Location -LiteralPath 'E:\新建文件夹 (8)'
.\demo.cmd
```

程序首先读取并显示真实的 Python 环境路径、Python、PyTorch、NumPy、Pandas、Matplotlib、Pillow 和 Git 版本，以及 PyTorch 的 CUDA 运行库、CUDA 是否可用和显卡名称；随后显示结果并提示输入图片路径。录屏时先讲环境，再切到结果图。

口播：

> 这是我的花卉分类项目，支持雏菊、蒲公英、玫瑰、向日葵和郁金香五类。
>
> 这里首先展示实际运行环境。项目使用已有的 Anaconda 环境，PyTorch 用于模型训练和识别，NumPy、Pandas 用于数据处理，Matplotlib 用于生成图表。
>
> 终端中显示了各个库的版本。CUDA 可用为 True，并识别到 RTX 5070 Laptop GPU，说明当前环境能够使用显卡加速。

若只想先单独检查环境，可在项目目录执行 `.\demo.cmd --environment-only`；该命令检查结束后会返回 PowerShell。

**二、展示主要结果**

打开的对照图就是已完成实验的结果。口播：

> 目前模型在原测试集上的准确率是 87.36%，另外 100 张网络检验图片上的准确率是 81%。图中是原模型与改进模型的对比，原数据集成绩提高，但网络检验从 85% 降到了 81%，说明对网上图片的识别还需要改进。
>
> 下面实际识别一张图片。

**三、找图片，执行识别**

在浏览器中找上述五类之一的图片，用“图片另存为”保存到：

`E:\新建文件夹 (8)\data\demo_images`

使用真实的 JPG、PNG 或 WebP 等支持格式，并保留来源链接。假如保存为 `rose01.jpg`，回到程序的“图片路径”提示处，粘贴下面这个路径并按回车；这里输入的是路径，不是新的终端命令：

```text
E:\新建文件夹 (8)\data\demo_images\rose01.jpg
```

把文件名换成自己实际保存的文件名。程序会打开图片，并在终端显示预测结果。第一行是预测类别：`daisy` 雏菊、`dandelion` 蒲公英、`roses` 玫瑰、`sunflowers` 向日葵、`tulips` 郁金香。

识别前口播：

> 这是我从网上保存的图片，现在把它输入程序。程序会加载训练好的模型，并输出预测类别和对应概率。

识别正确时口播：

> 第一行是预测结果，本次与图片的实际类别一致。后面的数值是模型给出的概率，不代表一定正确。

识别错误时口播：

> 这张图片识别错误，说明模型还会受到花形、背景和光照等因素影响，不能保证每张网络图片都识别正确。

想继续演示，就在下一次提示时粘贴另一张图片的完整路径。

**四、结束演示**

在“图片路径”提示处输入 `q` 并回车，即可退出；也可以按 `Ctrl+C`。

口播：

> 项目已经可以加载模型并识别本地图片。后续我会继续改进容易混淆的类别。以上就是本次演示，谢谢。
